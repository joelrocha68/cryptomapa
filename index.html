Status: configure seu projeto para ativar a sincronização.
Como funciona: o app transforma sua carteira em um único pacote, criptografa esse pacote no próprio dispositivo com AES-GCM e só então envia o texto criptografado ao Supabase. O e-mail/login serve para a regra de acesso do banco; a senha do cofre é o que protege o conteúdo.
Ver SQL para preparar o Supabase
create table if not exists public.cryptomapa_sync ( user_id uuid primary key references auth.users(id) on delete cascade, payload text not null, updated_at timestamptz not null default now() ); alter table public.cryptomapa_sync enable row level security; grant select, insert, update on public.cryptomapa_sync to authenticated; create policy "users_can_read_own_cryptomapa" on public.cryptomapa_sync for select to authenticated using ((select auth.uid()) = user_id); create policy "users_can_insert_own_cryptomapa" on public.cryptomapa_sync for insert to authenticated with check ((select auth.uid()) = user_id); create policy "users_can_update_own_cryptomapa" on public.cryptomapa_sync for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);
