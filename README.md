# CryptoMapa

PWA pessoal para consolidar criptomoedas espalhadas entre exchanges, carteiras próprias, hardware wallets e DeFi.

## Segurança
O CryptoMapa não pede seed phrase, chave privada, senha de exchange ou código 2FA.

## Versão publicada
CryptoMapa 13.1

## GitHub Pages
Depois de habilitar GitHub Pages com **GitHub Actions** em Settings → Pages, o app será publicado em:

https://joelrocha68.github.io/cryptomapa/

No Android, abra esse endereço no Chrome e use **Instalar app** / **Adicionar à tela inicial**.
