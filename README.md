# CryptoCheck

PWA pessoal para inventariar e reconciliar criptomoedas espalhadas entre exchanges, wallets, DeFi e locais antigos.

## Objetivo
Comparar:
- quanto você acredita ter;
- quanto realmente encontrou;
- onde cada saldo está;
- quanto vale em USD;
- o que ainda precisa investigar.

## Segurança
O CryptoCheck não pede seed phrase, chave privada, senha de exchange ou código 2FA.
